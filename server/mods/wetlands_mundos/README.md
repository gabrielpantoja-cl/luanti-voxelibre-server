# wetlands_mundos

Comando interno para recordar las direcciones de los mundos del proyecto.

## Comando

```text
/mundos
```

El comando se registra en Wetlands, GAELSIN, CTF y Mineclonia. Se omite en
Valdivia (`30001`), que es el unico mundo publico anunciado en la lista de
servidores.

El mod no registra nodos, texturas ni entidades. Para un mundo nuevo hay que
habilitarlo en su configuracion y en el `world.mt` correspondiente antes de
reiniciar el servidor.
